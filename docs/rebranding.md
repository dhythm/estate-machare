# Estate Machare — リブランディング設計

## ブランド

暮らしの次の一歩を、不動産との出会いから。
売買・賃貸を探す人、物件を掲載する人、引越しを支える人をつなぐサービスです。

## 情報設計

- 公開物件は写真、所在地、間取り、面積、築年、アクセス、売買価格・月額賃料で比較します。
- 購入・賃貸の検索と、内見・条件の問い合わせを主導線にします。
- 物件を所有する方には、売却・賃貸募集の掲載導線を提供します。
- 引越しを物件探しの次の行動として配置。物件からの依頼では所在地を引越し先に初期設定します。
- 引越し料金は荷物の規模と距離によるデモ参考額。実際の見積もりや契約・決済は提供していません。

## 視覚体系

主色はネイビー `#203a43`、背景はアイボリー `#f7f5f0`、強調色はテラコッタ `#b16b4e`。
住空間の写真と落ち着いた余白を使い、物件情報と次の操作が見つけやすい構成にします。
共通ヘッダー、フッター、ログイン、物件一覧・詳細、引越し、マイページ、運営画面の名称を統一します。

## 既存機能との互換性

APIのパス、取引ID、認証、審査、メッセージ、引越しの進行管理を維持します。
物件情報は専用の `property` に格納し、従来の日額を月額として読み替えません。
新物件は月額賃料と問い合わせを使い、旧日額予約・購入切替機能は既存データ向けに保持します。
引越しのAPIには既存の `transport` と `weight` フィールドを用い、画面では「引越し」「荷物量」と表示します。

## ビジュアルアセット

`public/estate-hero.webp` と `public/properties/*.webp` は本デモのために生成した架空の建築・物件イメージです。実在物件の写真ではありません。実運用では各掲載物件の写真に置き換えます。

## 既存データの互換性

物件情報は `property` に保存し、月額賃料と従来の日額契約を分離しています。既存DBの登録データは自動で書き換えません。新規デモデータは不動産向けです。
